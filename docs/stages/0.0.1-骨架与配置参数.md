## 目标

建立核心代理层的仓库骨架与唯一配置入口，为后续所有任务提供参数与编排基础。

## 产出

| 文件 | 职责 |
|---|---|
| `proxy/.env` | 唯一参数：`HOST_IP`、`CACHE_BASE` |
| `proxy/.gitignore` | **保护证书私钥**：`ca/*.key`、`ca/certs/` 绝不入库 |
| `proxy/docker-compose.yml` | 两个服务的编排：dnsmasq + tengine |

## 关键决策

**健康检查用 `127.0.0.1` 而非 `localhost`** — 容器内 `localhost` 解析为 `::1`，
而 nginx 只监听 IPv4，会导致健康检查恒假失败。这正是旧环境 `v3-tengine`
长期显示 `unhealthy` 的原因，此次从源头规避。
