## 内容要点

**用法**：`sudo ./client-setup.sh`（下载 CA）/ `--ca`（本地 CA）/ `--rollback`（回滚）

**未自动实施的可选加固**（影响整机网络行为，交由使用者决定）：

```bash
iptables -A OUTPUT -p udp --dport 443 -j REJECT      # 阻断 QUIC
iptables -A OUTPUT -p tcp --dport 853 -j REJECT      # 阻断 DoT
iptables -A OUTPUT -p udp --dport 853 -j REJECT
```

> 文档中说明了取舍：客户端此时已解析到 `.18`，QUIC 到 `.18` 的 UDP 443 无监听、
> 多数栈会回退 TCP；**真正的绕过路径是 DoH + 直连真实 IP**，故 DoT/DoH 的阻断
> 比 QUIC 更关键。

**排查表**收录了实机踩过的 4 个坑（CA 端点 / hosts 压制 / 防火墙 443 / conda CA bundle），
每条都写明现象与根因 —— 这些故障的共同点是「症状与根因相距很远」，不留文档下次仍会重踩。
