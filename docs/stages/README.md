# 阶段汇总

本目录存放 TProxy 各阶段（每个实施任务）的完成汇总，每完成一个阶段生成一份。

## 版本号规则

三位十进制、**逐位逢十进位**：

```
0.0.1 → 0.0.2 → … → 0.0.9 → 0.1.0 → 0.1.1 → … → 0.1.9 → 0.2.0
      → … → 0.9.9 → 1.0.0 → 1.0.1 → …
```

每一位取值 0–9，满 9 进 1 到高位，本位归零。**不跳号、不回退**。

## 命名约定

```
<版本号>-<阶段名>.md
```

例：`0.0.2-dnsmasq域名劫持.md`

## 每份汇总包含

| 项 | 说明 |
|---|---|
| 目标 | 本阶段要达成什么 |
| 产出 | 新增/修改的文件 |
| 关键决策 | 执行中的 Ruling 与理由 |
| 验证证据 | **实际命令与输出**，非推断 |
| 提交 | commit 范围 |
| 遗留 | 已知未决事项 |

> 验证证据一栏必须来自真实执行结果。没有跑过的验证不写入。
