# 0.1.1 — Python (PyPI) 缓存

**提交**：`d457ede`
**计划**：[计划 B Task 3](../plans/2026-09-23-phaseB-cache-backends.md)

## 目标

`pip install` 经代理从本机缓存取包。

## 产出

| 文件 | 职责 |
|---|---|
| `proxy/tengine/conf.d/python.conf` | pypi.org / files.pythonhosted.org 分流 |
| `proxy/tengine/nginx.conf` | 新增 `py_cache` 缓存区 |
| `proxy/tests/test-python.sh` | 验证脚本 |

## 缓存策略

| 内容 | TTL | 理由 |
|---|---|---|
| `/simple/` 索引 | **5 分钟** | 新版本发布必须及时可见 |
| `.whl` / `.tar.gz` / `.zip` / `.egg` | **365 天** | 文件名含版本与哈希，内容不变 |
| 其余 | 10 分钟 | — |

## 验证证据
