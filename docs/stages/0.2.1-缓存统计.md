# 0.2.1 — 缓存统计

**提交**：`200579d`
**计划**：[计划 D Task 2](../plans/2026-09-23-phaseD-management-ui.md)

## 目标

统计六类缓存的占用，供界面展示。

## 产出

| 文件 | 职责 |
|---|---|
| `manager/backend/cache_stats.py` | 目录占用统计 |

## 关键决策

**跳过 `.tmp` / `.temp` 临时文件**

nginx 写入缓存时先落临时文件。若把它计入统计，会出现两个问题：
统计值随写入抖动，且可能读到半截文件的大小。测试专门覆盖。

**未创建的目录也返回（值为 0、`enabled=false`）**

界面需要据此提示「该类未启用」，而不是静默不显示 ——
「不显示」和「显示为 0」在运维判断上差别很大。

**单个文件读取失败跳过而非中断**

缓存目录在遍历时可能正被 nginx 修改（文件被删除）。一个 `OSError`
不应让整次统计失败。
