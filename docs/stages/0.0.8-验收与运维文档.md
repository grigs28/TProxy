## 计划 A 交付总结

**达成**：客户端只需 ① 把 DNS 指向 `192.168.0.18`、② 安装一次根 CA，
系统包（dnf / yum / apt）请求即自动命中本地缓存，客户端配置文件一字未改。

**交付物**：

```
proxy/
├── docker-compose.yml      dnsmasq + tengine
├── .env                    唯一参数
├── deploy.sh               一键部署
├── ca/                     根 CA、签发脚本、域名清单
├── dnsmasq/                劫持配置 + 内网 hosts + Dockerfile
├── tengine/                主配置 + 分流规则
├── tests/                  5 个测试 + 验收脚本
└── docs/OPERATIONS.md      运维说明
```

**验证方式**：5 组测试全绿，两个容器 healthy，端到端实测存在缓存命中。
