## 目标

建立客户端接入脚本的骨架，以及决定后续分支的两个检测函数。

## 产出

| 文件 | 职责 |
|---|---|
| `client/lib/detect.sh` | `detect_distro()` / `detect_dns_manager()` |
| `client/tests/test-detect.sh` | 检测逻辑验证 |

## 关键发现：大小写敏感的漏判

首版 `detect_distro()` 在开发机上返回 `unknown`，而该机是 openEuler。
查 `/etc/os-release`：

```
ID="openEuler"        ← 大写 E
```

而匹配模式写的是小写 `*openeuler*`，**大小写敏感导致漏判**。
修复：先用 `tr` 转小写再匹配。

> 这个 bug 由测试直接抓到 —— 也说明「检测函数必须有测试」不是形式主义：
> 它错了不会报错，只会让后续所有分支走错。

测试还含一条「干净环境可运行」断言（`env -i` 下执行），防止函数隐式依赖调用方变量。

## 验证证据

  ✅ 检测到: networkmanager
