## 关键决策

**配置与缓存均只读挂载**

```yaml
volumes:
  - /opt/TProxy/proxy:/opt/TProxy/proxy:ro
  - ${CACHE_BASE}:${CACHE_BASE}:ro
```

界面只做展示与诊断，**不直接写文件**。理由：界面写规则会与运维手工编辑
互相覆盖，且在没有认证机制的情况下，开放写权限风险过高。
「新增上游」仍走文档化的三处改动流程。

**`test-manager.sh` 断言「数据非空」而非「接口返回 200」**

这是刻意针对旧 `proxy-manager` 的失败模式：接口正常、界面全空、不报任何错。
因此必须断言「解析出 N 条规则」「列出 N 张证书」这类**内容**层面的条件。
