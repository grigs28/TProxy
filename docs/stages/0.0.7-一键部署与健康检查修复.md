## 关键决策：补 `default_server` 兜底块

部署脚本本身五步全过，但**暴露出 `v3-tengine` 处于 `unhealthy`**。诊断结果：

```
Health check exceeded timeout (5s)
```

根因：健康检查请求的 `Host: 127.0.0.1` 不匹配任何 `server_name`，
nginx 于是落到第一个 server 块，而它的 `proxy_pass $scheme://$host$request_uri`
把请求**代回了代理自己**（`$host` 解析为 `127.0.0.1`）—— 死循环，必然超时。

修复两处：

```nginx
server {
    listen 80 default_server;
    server_name _;
    location = /healthz { return 200 "ok\n"; }
    location / { return 444; }        # 未知 Host 直接关闭连接
}
```

健康检查路径同步改为 `http://127.0.0.1/healthz`。

这不只是修健康检查 —— **未知 Host 会导致代理自环**是真实缺陷，
若不加兜底，任何指向本机但 Host 未匹配的请求都会打回自己。
