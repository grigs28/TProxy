## 关键决策

**所有路径经环境变量注入**

使测试可在临时目录上运行，不触碰真实配置与缓存。
这比 mock 掉文件系统更简单，也更接近真实行为。

**仅绑定回环地址 `127.0.0.1`**

管理界面**没有认证机制**。绑回环意味着只能从本机（或经 SSH 隧道）访问 ——
在补齐认证之前，这比暴露到内网安全得多。容器用 host 网络，因此这一约束
在容器化后依然成立。

**`/api/rules` 在无配置时返回空列表而非 500**

界面据此显示「未解析到规则」的明确提示。返回 500 会让前端只能显示
泛化的错误，掩盖了「配置路径不对」这一具体原因。
