## gitcache 健康检查修正

验收时发现 `v3-gitcache` 显示 `unhealthy`。根因：Dockerfile 里健康检查探的是
**5000** 端口（实际用 **4999**），且用的是 HTTP 请求 —— 而 gitcache 是 git 协议
代理、非网页服务器，对 `/` 的请求必然失败。

改为探端口：`CMD nc -z 127.0.0.1 4999`。容器转为 `healthy`。
