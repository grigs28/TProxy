## 与 es-21/es-22 的关键差别

**这台机器 GitHub 直连是通的**（`20.205.243.166 → HTTP 200`），
所以「git 不走代理」在这里**字面可行** —— git 装了就能直接用。

es-21/es-22 直连全超时，同样的配置等于「git 断网」；这三台的情况**不能混用一套判断**，
所以 SOP 第 0 步的直连探测是必须做的。
