# 方案：新机器接入 TProxy（含各变体）

> 一份可直接照做的 SOP。2026-11-08 以 es-21/es-22 两台机器沉淀。

## 0. 动手前的三个必查

```bash
# ① 能否登录（root 优先）
sshpass -p '<密码>' ssh -o StrictHostKeyChecking=no root@<IP> 'echo OK'

# ② 什么系统（决定包管理器：openEuler→dnf，Debian/PVE→apt）
ssh root@<IP> 'grep PRETTY_NAME /etc/os-release; hostname'

# ③ 能否直连 GitHub（决定「git 不走代理」是否可行）
ssh root@<IP> 'curl -s -o /dev/null -w "%{http_code}" -m 8 \
  --resolve github.com:443:20.205.243.166 https://github.com/'
```

**③ 的结果决定 git 部分怎么做：**

| 直连结果 | 含义 | git 方案 |
|---|---|---|
| 200 | 能直连（如 .14/.19） | pin 真实 IP 即可，git 照常能用 |
| 超时 | 唯一出网路径是 .18（如 .6/.128/.129/.143） | 「不走代理」= git 断网。**必须先跟用户确认这是要的** |

## 1. 标准接入（全功能）

```bash
# 传脚本
sshpass -p '<密码>' scp client/dist/tp.client.sh root@<IP>:/root/
# 接入（DNS 指 .18 + 装 CA + 修源 + 自检）
ssh root@<IP> 'bash /root/tp.client.sh -i'
```

`-i` 做的事：DNS 指 `.18`（+ 223.5.5.5 兜底）、装根 CA（四处）、修复损坏的源、
**清掉 /etc/hosts 里的公网 pin**、最后跑 44 个域名的自检。

部分接入：`-c`（只装证书）/ `-d`（只改 DNS）/ `-s`（查状态）/ `-r`（回滚）。

## 2. 变体：git 不走代理（本次 es-21/es-22 场景）

**`-i` 会清掉 hosts 里的 github pin，让 git 走代理。** 要排除 git，跑完 `-i` 后把 pin 加回来：

```bash
ssh root@<IP> 'cat >> /etc/hosts <<EOF

# git 不走 TProxy 代理（用户指定 <日期>），pin 到真实 IP
20.205.243.166  github.com www.github.com
185.199.108.133 raw.githubusercontent.com
EOF'
```

hosts pin 优先级高于 DNS 劫持，git 流量从此不经 `.18`。

**恢复走代理**：删掉这几行即可（git 自动回落到 DNS 劫持 → .18）。

## 3. 验证清单（每台必做）

```bash
ssh root@<IP> '
# DNS 劫持生效（应全指 .18）
getent hosts repo.openeuler.org mirrors.aliyun.com pypi.org

# HTTPS 经代理（CA 信任链）
curl -s -o /dev/null -w "%{http_code}\n" -m 15 https://repo.openeuler.org/
# → 302 为正常（openEuler 的重定向）

# 包管理器真实流程
dnf makecache --refresh        # openEuler
# apt-get update               # Debian/PVE
'
```

通过标准：

| 检查 | 期望 |
|---|---|
| 劫持域名 `getent` | 全部 `192.168.0.18` |
| `https://repo.openeuler.org` | 302（不是证书错误） |
| `dnf makecache` / `apt-get update` | 退出码 0，无 404/证书错误 |
| git 不走代理的变体 | `getent hosts github.com` 返回真实 IP 而非 .18 |

## 4. 踩过的坑（别再踩）

1. **`-i` 会清 hosts pin** —— 任何「某某域名要走特殊路径」的 pin，跑完 `-i` 都要检查还在不在
2. **「git 不走代理」先查直连** —— 内网不少机器唯一出网路径就是 .18，pin 真实 IP = git 断网
3. **改完名顺手把新主机名写进 /etc/hosts 的 127.0.0.1 行**，否则 sudo 会报「无法解析主机名」
4. **Docker 机器接入后要 `systemctl restart docker`** 才走 registry 缓存（脚本会提示）
5. **禁区机器**（.21/.22/.29/.30/.80–.84）不在此流程适用范围，接入前先对照
   `fleet-forbidden-hosts` 记忆
