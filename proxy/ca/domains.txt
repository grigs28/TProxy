# proxy/ca/domains.txt —— 需签发证书的域名，每行一个
#
# ⚠️ **本文件必须覆盖 dnsmasq 的全部劫持域名，一个都不能少。**
#    `deploy.sh` 是靠**遍历本文件**来签发证书的 —— 某个劫持域名若不在
#    这里，**CA 重建后它就没有证书**，而 tengine 又确实在服务它，
#    结果是「劫持了却拿不出匹配的证书」，客户端的 HTTPS 直接断
#    （实测症状：`SSL connect error ... tlsv1 alert internal error`）。
#
#    这个坑很隐蔽：**证书是长期有效的，CA 重建又极少发生** ——
#    所以漏掉一个域名可能几个月都不出事，直到某次重建才集体爆掉。
#    实测 2026-09-26：本文件曾缺 7 个域名（正是 0.5.5 新增的那批），
#    而 .18 上证书齐全，属于「已埋雷但未引爆」。
#
#    守卫：`proxy/tests/test-dns.sh` 会断言「劫持清单 ⊆ 本文件 ⊆ 已签证书」。
#
