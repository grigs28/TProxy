📝 hosts-master.txt 单文件配置

通过 hosts-master.txt 统一管理域名解析规则。修改后保存会自动重启配置生成器。

📖 配置格式说明

; @category <类别>        - 缓存分类 (docker/yum/pypi/github/other)
; @cache <过期时间>         - 缓存时间 (30d, 7d, 1h)
; @real-ip <IP:端口>       - 源站真实地址 (用于回源)
; @nocache                   - 禁用缓存
; @desc <描述>             - 备注说明

address=/<域名>/<代理IP>     - 域名解析规则

# 示例:
; @category docker
; @cache 30d
; @real-ip 54.236.113.205:443
address=/docker.io/192.168.0.36
